01 / ABOUT AION

不只是一个 AI 聊天工具。
而是一套完整的交易系统。

AION 将 AI 的研究与推理能力、量化引擎的确定性计算、独立风控和交易执行连接起来。Android 客户端负责查看状态与发送控制指令，云端负责持续运行、数据处理与任务编排。

面向大众，注册即用

Android 客户端连接 AION 服务器后，可以登录、开启托管并查看账户与持仓。每个用户的 API Key、策略、持仓与学习记录彼此隔离。系统围绕 Binance USDⓈ-M Futures 设计，账户、行情、策略、风险、订单与审计信息都在客户端内完成。

系统强调可解释、可追溯与安全边界：AI 负责分析并提交结构化交易意图；独立风控引擎负责审核；只有执行引擎可以向交易所提交订单。真实下单后立即挂保护单，云端持续巡检并自动平仓。

Market Regime Agent

市场状态识别

识别趋势、震荡、高波动与低流动性状态，给出证据、置信度和不确定性。

02

Technical Analysis Agent

技术结构分析

分析多周期结构、指标、关键价位与技术形态，不编造价格或指标。

03

Derivatives Analysis Agent

衍生品数据分析

分析资金费率、未平仓量、基差等可获取数据，缺失数据会明确标记。

04

Strategy Research Agent

策略研究与验证

提出策略假设、参数范围、失效条件和验证计划，不直接下单。

05

Chief Trading Decision Agent

首席交易决策

综合各方分析，输出结构化 TradeIntent 或 NO_TRADE。

06

Adversarial Review Agent

对抗审查 · 一票否决

寻找反向证据、数据质量问题、过拟合与事件风险；拥有 VETO 权限，可以直接否决本次交易。

六个 AI 是系统内的职责角色，可由不同大模型驱动；立绘为模型品牌展示，不代表某个 Agent 固定绑定某个模型，每个 Agent 都可以使用不同的模型。

03 / CORE ENGINES

从研究，到信号，再到受控执行。

AION 不是让大模型直接控制交易所，而是把概率性分析与确定性交易规则分层处理。

01

Quant Engine · 量化引擎

负责确定性指标计算、多周期聚合、波动率与风险收益比估算，以及回测数据处理。AI 解释数据、提出假设，不替代量化计算。

EMA / SMARSI / MACDATR / Bollinger逐根 OHLCV
02

Strategy Engine · 策略引擎

管理策略假设、版本、参数、适用市场、失效条件和验证结果。策略必须经过对应阶段与明确批准，不能自行越级进入真实交易。

ResearchBacktestPaperShadowApproved / Active

Risk Engine · 独立风控

独立检查交易模式、交易对白名单、杠杆、名义价值、亏损预算、总敞口、保证金、行情新鲜度、熔断状态和订单对账情况。

自动开仓

自动止盈止损

自动平仓

TP / SL日内超时reduceOnly
